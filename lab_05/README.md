# Лабораторна робота №5: Аналіз вегетаційних індексів через Streamlit

## Опис проєкту
Цей веб-додаток призначений для візуалізації та аналізу даних вегетаційних індексів (VCI, TCI, VHI) на основі даних NOAA. Додаток дозволяє фільтрувати дані за областями, роками та тижнями, а також порівнювати показники між різними регіонами України.

## Структура інтерфейсу
Відповідно до завдання:
- **Ліва колонка:** Елементи керування (вибір показника, області, інтервалів часу, кнопки скидання та сортування).
- **Права колонка:** Основний контент (таблиця з даними, графік часового ряду та графік порівняння областей у вкладках).

## Як запустити
1. Переконайтеся, що у вас встановлено Python.
2. Створіть та активуйте віртуальне середовище:
   `python -m venv venv`
   `venv\Scripts\activate`
3. Встановіть необхідні бібліотеки
4. Запустіть додаток:
   `python -m streamlit run lab5.py`

Для коректної роботи додатка у папці має бути присутній файл `vhi_clean_data.csv`, згенерований у лабораторній роботі №2.
