## Опис роботи
У цій лабораторній роботі проведено аналіз та візуалізацію даних на основі унікального датасету **Automobile Dataset** з репозиторію UCI Machine Learning.

### Виконані завдання:
1. **Завантаження та Data Cleaning:** - Обробка пропущених значень (NaN), позначених як `?`.
   - Видалення рядків з відсутньою цільовою змінною (`price`).
   - Заповнення числових пропусків середнім значенням, а категоріальних — модою.
2. **Базова візуалізація:**
   - Побудовано графіки залежності (Scatter plot, Line plot) між числовими атрибутами.
   - Побудовано гістограму розподілу цін рівно на 5 заданих діапазонів.
3. **Багатовимірна візуалізація:**
   - Створено багатовимірний Bubble Chart (4 виміри: ціна, об'єм двигуна, тип палива, потужність).
   - Відображено розподіл цін за допомогою Boxplot з урахуванням типу кузова та приводу.
   - Побудовано теплову карту (Heatmap) кореляції основних характеристик автомобілів.

## Інструменти
* Python 3
* Pandas, NumPy

## Вимоги до системи та встановлення
Для запуску проєкту на вашому комп'ютері має бути встановлений **Python версії 3.9 або вище**.

### Інструкція зі встановлення залежностей:
1. Зклонуйте репозиторій та перейдіть у папку з лабораторною:
cd lab_03
2. Створіть та активуйте віртуальне середовище:
python -m venv venv та venv\Scripts\activate

3. Встановіть необхідні залежності з файлу requirements.txt:
pip install -r requirements.txt
4. Запустіть Jupyter Notebook для перегляду результатів:
jupyter notebook
