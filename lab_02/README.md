# Лабораторна робота №2: Pandas та Data Analysis

## Опис завдання
**Частина 1:** Завантаження та очищення даних VHI-індексу для адміністративних одиниць України з сервера NOAA. Зміна індексів областей за українською абеткою, формування вибірок та пошук екстремумів.
**Частина 2:** Аналіз великого датасету Individual Household Electric Power Consumption. Очищення даних, формування логічних вибірок, нормалізація, стандартизація, One Hot Encoding та підрахунок коефіцієнтів кореляції. Аналіз часових витрат за допомогою модуля timeit.

## Вимоги до системи та версії інтерпретатора
- **ОС:** Windows / Linux / macOS
- **Інтерпретатор:** Python 3.9 або вище

## Команди для встановлення залежностей та інструкція із запуску
1. Перейдіть до директорії лабораторної роботи:
   cd lab_02
2. Створіть та активуйте віртуальне середовище:
Для Windows:
python -m venv venv
venv\Scripts\activate
3. Встановіть необхідні залежності з файлу requirements.txt:
pip install -r requirements.txt
4. Запустіть Jupyter Notebook для перегляду та виконання коду:
jupyter notebook
