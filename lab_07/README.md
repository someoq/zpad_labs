# Лабораторна робота №7: Computer Vision та багатопотоковість у C++

## Опис завдання
Проєкт реалізує систему розпізнавання облич у реальному часі з використанням нейромереж та багатопотокового програмування. Основна мета — поєднати обробку відео OpenCV із асинхронними обчисленнями для забезпечення максимальної плавності інтерфейсу (Рівень 2).

**Ключові особливості:**
- **Детекція облич:** Використання моделі ResNet-10 (SSD) через модуль `cv::dnn`.
- **Багатопотоковість:** Обчислення нейромережі винесені в окремий потік (`std::thread`), що дозволяє уникнути фризів відео.
- **Синхронізація:** Використання м'ютексів (`std::mutex`) для безпечного доступу до спільних ресурсів.
- **Демонстраційне навантаження:** Додано затримку 500 мс у фоновому потоці для перевірки асинхронності.

---

## Вимоги до ОС та компілятора
- **Операційна система:** Ubuntu Linux 20.04+ (або Windows з WSL2).
- **Компілятор:** GCC 9.0+ з підтримкою стандарту C++17.
- **Система збірки:** CMake 3.10 або новіше.
- **Бібліотеки:** OpenCV (libopencv-dev).
- **Моделі:** deploy.prototxt та res10_300x300_ssd_iter_140000.caffemodel.

---

## Архітектура (Класи та потоки)
Проєкт реалізовано за модульним принципом:
- **Клас FaceDetector**: Головний вузол, що керує фоновим потоком. Містить об'єкт нейромережі, м'ютекс для захисту кадрів та логіку інференсу.
- **Main Thread**: Відповідає за стабільне відображення відео (UI) та обробку клавіш.
- **Worker Thread**: Постійно працює у фоні, обробляючи кадри нейромережею незалежно від швидкості рендеру основного вікна.

## Інструкція налаштування і запуску

### 1. Надання прав на виконання скриптів
chmod +x preinstall.sh build.sh run.sh
### 2. Встановлення залежностей та завантаження нейромережі
Скрипт встановить необхідне ПЗ та автоматично завантажить файли моделі:
./preinstall.sh
### 3. Компіляція проєкту
Скрипт скомпілює бінарний файл Lab7_OpenCV:
./build.sh
### 4. Запуск програми
./run.sh
