# Лабораторна робота №6: Обробка відео з OpenCV (C++)

## Опис завдання
Проєкт реалізує програму на C++ з використанням бібліотеки OpenCV. Програма в реальному часі захоплює відео з веб-камери, відображає його у вікні та дозволяє користувачу взаємодіяти із зображенням за допомогою клавіатури та миші. 

Реалізовано модульну архітектуру (ООП). Доступні функції:
- Накладання фільтрів (Інверсія, Gaussian Blur, Canny Edge).
- Керування яскравістю через інтерактивний слайдер.
- Малювання геометричних фігур (прямокутник) за допомогою миші.

---

## Вимоги до ОС та компілятора
- **Операційна система:** Ubuntu Linux 20.04+ (або Windows з налаштованим WSL2 + WSLg).
- **Компілятор:** GCC 9.0+ або Clang 10.0+ (з підтримкою стандарту C++17).
- **Система збірки:** CMake 3.10 або новіше.
- **Бібліотеки:** OpenCV (libopencv-dev).
- **Апаратне забезпечення:** Наявність веб-камери.

---

## Інструкція налаштування і запуску

Для зручності проєкт містить скрипти автоматизації. Перед першим запуском переконайтеся, що скрипти мають права на виконання. 

### 1. Надання прав на виконання скриптів (одноразово)
chmod +x preinstall.sh build.sh run.sh
### 2. Встановлення залежностей
Скрипт оновить систему та встановить необхідні інструменти (GCC, CMake, OpenCV):
./preinstall.sh
### 3. Компіляція проєкту
Скрипт створить директорію build, згенерує файли CMake та скомпілює бінарний файл:
./build.sh
### 4. Запуск програми
Скрипт запустить готовий бінарний файл з папки build:
./run.sh
